# Prompt Master Criades V7.1.2

## Revisió del motor bilingüe
Aquesta versió se centra en la qualitat lingüística dels textos generats.

### Canvis
- Reescriptura del motor de text ES/EN amb blocs gramaticalment tancats.
- Eliminació de construccions que inserien directament infinitius del selector en frases que exigien gerundi o altres formes verbals.
- Castellà i anglès tenen redaccions pròpies a partir de les mateixes dades d'escena.
- Es mantenen els tipus: narratiu, descriptiu, documental, catàleg d'uniformes, diàleg, reflexió, anècdota, crònica professional i editorial.
- Es conserven els controls i el generador visual de V7.1.1.
